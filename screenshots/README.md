# Sweety – Screenshots

This directory contains genuine screenshots captured directly from the live running application:

1. `01_Login.png`: Login screen showing clean pastel card layout, credentials inputs, and "Fill Demo Credentials" helper.
2. `02_Signup.png`: Account registration form with full name, email, and password.
3. `03_Dashboard.png`: Dashboard showing patient greeting, date navigation, 4 slot cards, target counter, and statistics.
4. `04_Add_Reading.png`: Log Blood Glucose modal with slot picker, numeric glucose input, and date picker restricted to today.
5. `05_Validation.png`: Inline validation alert showing duplicate slot rejection.
6. `06_Reading_History.png`: Historical reading log with date filtering and pagination.
7. `07_Edit_Delete.png`: Delete confirmation dialog preventing accidental data removal.
8. `08_Daily_Report.png`: Daily report with highest, lowest, average, and slots list.
9. `09_Monthly_Report.png`: Previous-month aggregate report with trend line chart.

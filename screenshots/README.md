# Sweety – Screenshots Checklist

This directory is designated for project visual assets and screenshots for evaluation.

### Suggested Screenshot Checklist:
1. `01_login.png`: Login screen showing clean pastel card layout and demo login helper.
2. `02_signup.png`: Account registration form with full name, email, and password.
3. `03_dashboard.png`: Dashboard showing patient greeting, date navigation, slot cards, and statistics.
4. `04_reading_modal.png`: Reading modal with time slot dropdown, numeric input, and validation rules.
5. `05_reading_history.png`: Historical reading log with date filtering and pagination.
6. `06_reports_daily.png`: Daily report with highest, lowest, average, and slots list.
7. `07_reports_monthly.png`: Previous-month aggregate report with trend line chart.
8. `08_delete_confirm.png`: Delete confirmation dialog preventing accidental data removal.
